## 9. ANALISIS RESIKO & MITIGASI

| Resiko | Dampak | Mitigasi |
|--------|--------|----------|
| Harga terlalu murah (di bawah nilai) | Persepsi kualitas rendah | Positioning sebagai "Paket Hemat/Value" bukan premium |
| Pembajakan / sharing lisensi | Kehilangan revenue | Lisensi key per komputer (hardware lock) |
| Support membebani | Biaya tersembunyi | Batasi support 3 bulan, tawarkan paket support berbayar |
| Update versi menambah beban | Biaya maintenance | Update minor gratis 6 bulan, major upgrade berbayar |
| Kompetitor murah | Kehilangan penjualan | Tambah value (source code option, template, training) |
| Workflow klien kompleks | Scope creep | Tegas: custom workflow = biaya tambahan |
